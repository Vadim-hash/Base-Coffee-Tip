# Base Coffee Tip

A seamless, decentralized micro-tipping protocol built on the Base network. Designed to empower creators, developers, and open-source contributors to receive direct, peer-to-peer ETH support without intermediary fees or platform censorship.

## System Mechanics
* **Frictionless Tipping:** Enables supporters to send native ETH tips alongside on-chain, immutable memo messages in a single transaction.
* **Creator Registry:** Maintains an organized mapping of creator addresses to track total tips received and engagement metrics.
* **Instant Liquidity:** Unlike traditional Web2 platforms, funds are instantly settled in the creator's wallet with zero withdrawal delays.

## Integration
The contract provides clear event emissions (`TipReceived`), making it highly optimized for real-time frontend indexing and dynamic dApp dashboards.
